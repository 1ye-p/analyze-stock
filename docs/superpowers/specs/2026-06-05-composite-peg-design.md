# 复合PEG估值体系设计

> 日期：2026-06-05
> 状态：待审批

---

## 一、问题

当前Skill的PEG计算使用单季度同比增速：`PEG = PE / Q1净利增速(%)`

**低基数陷阱**：
- 兆易创新：Q1净利+522.8%（去年Q1亏损）→ PEG 0.23（假低估），年度PEG 2.40（真高估）
- 金山办公：Q1净利+445.0%（去年Q1低基数）→ PEG 0.07（假低估），年度PEG 2.58（真高估）

**PE类型混淆**：
- 腾讯API返回"动态PE"（基于最新季报年化），季节性强的公司严重失真
- 缺少TTM PE（基于最近4个季度实际EPS）作为校验

---

## 二、方案：复合PEG + 双PE体系

### 2.1 双PE输出

同时输出TTM PE和动态PE，差异>30%时标注警告。

```
TTM PE  = 当前价格 / TTM EPS
动态PE  = 当前价格 / 动态EPS（最新季度EPS × 4）

TTM EPS  = 最近4个季度单季EPS之和
动态EPS  = 最新季度EPS（年化）
```

### 2.2 复合PEG计算

用4个季度单季增速的几何平均消除低基数效应。

```
单季净利提取（从累计值反推）：
  Q1单季 = Q1累计值
  Q2单季 = 中报累计 - Q1累计
  Q3单季 = 三季报累计 - 中报累计
  Q4单季 = 年报累计 - 三季报累计

单季YoY增速：
  g_n = (本期Qn净利 - 上年Qn净利) / |上年Qn净利|

复合增速（几何平均）：
  G = [(1+g1) × (1+g2) × (1+g3) × (1+g4)]^(1/4) - 1

复合PEG：
  PEG_composite = TTM PE / (G × 100)
```

### 2.3 异常处理

| 场景 | 处理方式 |
|------|---------|
| 某季度净利为负 | 跳过该季度，用剩余正盈利季度计算，标注"数据不完整({原因})" |
| 连续2+季度为负 | 标注"无法计算复合PEG"，仅输出TTM PE |
| 上年同期为负 | 该季度增速取绝对值处理，标注"低基数" |
| 上年同期为0 | 跳过该季度，标注"上年同期为零" |

## 三、数据源

### 3.1 东方财富F10 API

```
URL: https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/ZYZBAjaxNew?type=0&code={市场代码}{股票代码}
```

返回数据（按时间倒序）：

| 索引 | 报告期 | 含义 | 提取单季值 |
|------|--------|------|-----------|
| [0] | 2026Q1 | Q1累计 | 直接使用 |
| [1] | 2025年报 | 全年累计 | [1]-[2]=Q4 |
| [2] | 2025三季报 | Q1+Q2+Q3 | [2]-[3]=Q3 |
| [3] | 2025中报 | Q1+Q2 | [3]-[4]=Q2 |
| [4] | 2025一季报 | Q1累计 | 直接使用 |
| [5] | 2024年报 | 上年全年 | [5]-[6]=上年Q4 |

关键字段：
- `PARENTNETPROFIT`：归母净利润
- `PARENTNETPROFITTZ`：归母净利润同比增速
- `EPSJB`：基本每股收益
- `TOTALOPERATEREVE`：营业总收入
- `TOTALOPERATEREVETZ`：营收同比增速

### 3.2 腾讯财经API（行情）

```
URL: https://qt.gtimg.cn/q={市场代码}{股票代码}
```

返回：当前价格、PE、PB、52周高低等。

## 四、输出格式

### 4.1 估值分析区块（替换原3.3节）

```
【估值分析】
  TTM PE：35.88（基于最近4个季度实际EPS）
  动态PE：38.35（基于最新季度年化）
  两者差异：+6.9%（正常）

  复合PEG计算明细：
  ┌──────────┬──────────┬──────────┬──────────┐
  │ 季度      │ 单季净利  │ 上年同期  │ 单季增速  │
  ├──────────┼──────────┼──────────┼──────────┤
  │ 2026Q1   │ 105.9亿  │ 52.3亿   │ +102.5%  │
  │ 2025Q4   │ 128.0亿  │ 80.8亿   │ +58.5%   │
  │ 2025Q3   │ 103.8亿  │ 64.1亿   │ +62.0%   │
  │ 2025Q2   │ 15.2亿   │ 10.1亿   │ +51.1%   │
  └──────────┴──────────┴──────────┴──────────┘
  复合增速（几何平均）：+67.2%
  TTM净利润：352.9亿
  TTM EPS：1.78元
  复合PEG = 35.88 / 67.2 = 0.53

  评估：低估（PEG<0.8）
```

### 4.2 异常情况输出示例

```
【估值分析】
  TTM PE：-（公司亏损）
  动态PE：30.50（基于最新季度年化）
  ⚠️ 数据不完整：2025Q2/Q3亏损，跳过2个季度

  复合PEG计算明细：
  ┌──────────┬──────────┬──────────┬──────────┐
  │ 季度      │ 单季净利  │ 上年同期  │ 单季增速  │
  ├──────────┼──────────┼──────────┼──────────┤
  │ 2026Q1   │ 2.6亿    │ 0.3亿    │ +901.7%  │
  │ 2025Q4   │ 2.3亿    │ -6.3亿   │ 低基数    │
  │ 2025Q2   │ -0.9亿   │ -        │ 跳过(亏损)│
  │ 2025Q3   │ -0.9亿   │ -        │ 跳过(亏损)│
  └──────────┴──────────┴──────────┴──────────┘
  ⚠️ 仅2个季度数据可用，复合PEG参考性有限
  复合增速：+901.7%（仅Q1，低基数）
  复合PEG = 164.99 / 901.7 = 0.18

  评估：⚠️ 数据不完整，PEG仅供参考
```

## 五、评分标准调整

原3.3节评分标准保持不变，但增加TTM PE校验：

```
评分标准：
  10分：复合PEG < 0.8 且 TTM PE < 30
  7分：复合PEG 0.8~1.0 或 TTM PE 30~50
  5分：复合PEG 1.0~1.5 或 TTM PE 50~80
  3分：复合PEG 1.5~2.0 或 TTM PE > 80
  0分：复合PEG > 2.0 或 无法计算
```
