# analyze-stock Skill V2 框架重构设计

> 日期：2026-06-05
> 状态：待审批

## 一、当前框架问题

### 1.1 分类边界模糊
- "套牢盘供给压力"本质是技术面，被归入基本面
- "预期差方向"本质是基本面，被归入板块
- 趋势/Fib/Price Action高度相关，同一信息被计3次分

### 1.2 权重分配缺乏实证
- 技术面45%偏高，中长期投资基本面更重要
- 10%权重差距太小，缺乏"一票否决"机制

### 1.3 评分标准缺乏量化锚点
- "完美趋势""近期回调"等描述无客观边界
- 不同分析者可能给出不同分数

### 1.4 缺失维度
- 无现金流估值（FCF）
- 无波动率分析（ATR/Beta）
- 无实时资金流向（北向/融资融券）
- 无事件驱动监控

## 二、V2 框架设计

### 2.1 四大类 × 十维度

```
┌─────────────────────────────────────────────────────┐
│  价格分析（30%）                                     │
│    ① 趋势结构    10%   道氏理论高低点序列           │
│    ② 量价关系    10%   威科夫吸筹/派发              │
│    ③ 价格形态    10%   K线形态+周线MACD金叉+窄幅震荡│
│                                                      │
│  基本面分析（35%）                                   │
│    ④ 增长质量    12%   营收/净利增速、毛利率趋势    │
│    ⑤ 估值合理性  12%   TTM PE、复合PEG、FCF Yield  │
│    ⑥ 预期差      11%   财报vs一致预期               │
│                                                      │
│  市场情绪（20%）                                     │
│    ⑦ 分析师动向   8%   上调/下调预测趋势            │
│    ⑧ 资金流向     7%   北向资金+融资融券+板块热度   │
│    ⑨ 事件驱动     5%   可能改变基本面的事件         │
│                                                      │
│  风险评估（15%）                                     │
│    ⑩ 风险因子    15%   波动率+流动性+杠杆+套牢盘    │
└─────────────────────────────────────────────────────┘
```

### 2.2 评分规则

- 基础分0~10分
- 特殊信号允许超过10分（如周线MACD金叉+窄幅震荡突破 = 13分）
- 最终加权分 = Σ(维度分 × 权重)
- 满分可能超过100分（理论上最高约115分），按比例折算或直接使用原始分

## 三、各维度详细设计

### 3.1 趋势结构（10%）— 量化版 + 周线MACD金叉加分

```
基础评分（道氏理论高低点序列）：
  高点升：最近3个波段高点，每个比前一个高>3%
  低点升：最近3个波段低点，每个比前一个高>3%

  10分：高点升+低点升，且距52周高点<10%
  7分：高点升+低点升，但近期有回调（距高点10~25%）
  5分：横盘震荡（高低点变化<3%）
  3分：高点降或低点降（下降趋势）
  0分：持续创新低（高点降+低点降）

周线MACD金叉加分（允许超过10分）：
  +3分：周线MACD金叉（DIF上穿DEA，且在0轴附近或上方）
  +2分：金叉前有4周以上窄幅震荡
         窄幅震荡定义：过去4~8周的周振幅均值/均价 < 8%
  +1分：金叉时成交量放大（周成交量>前4周均值的1.2倍）

  最强信号：横盘突破+周线MACD金叉+窄幅震荡+放量 = 10+3+2+1 = 16分
```

### 3.2 量价关系（10%）— 威科夫阶段

```
评分：
  10分：缩量企稳+需求回归（底部吸筹完成，Spring确认）
  7分：缩量下跌（供给枯竭，底部信号）
  5分：量价正常，无明显信号
  3分：放量下跌（供给涌现）
  0分：放量暴跌（恐慌性抛售）
```

### 3.3 价格形态（10%）— K线形态识别

```
评分（不超过10分）：
  10分：口袋支点（放量阳线，量超前10日最大阴线量）
  7分：底部形态（双底/头肩底）
  5分：无明显形态
  3分：高位滞涨/射击之星
  0分：放量大阴线/破位
```

> 注：周线MACD金叉加分已归入趋势结构（3.1节），不在本维度重复计算。

### 3.4 增长质量（12%）— 多维度评估

```
评估指标（综合判断）：
  □ 营收增速（Q1同比 + 年度同比）
  □ 净利增速（Q1同比 + 年度同比）
  □ 毛利率趋势（季度环比，连续2季下降为预警）
  □ 经营现金流 vs 净利润（现金流>净利为优）

评分：
  10分：营收+50%以上，利润增速>营收增速，毛利率上升，现金流>净利
  7分：营收+20~50%，利润同步增长，毛利率稳定
  5分：营收+10~20%，增长平稳
  3分：营收增速<10%或增收不增利
  0分：营收负增长或亏损扩大

加分项（允许超过10分）：
  +2分：毛利率连续3个季度上升
  +1分：经营现金流/净利润 > 1.5（利润质量极高）
```

### 3.5 估值合理性（12%）— 多指标体系

```
核心指标：
  TTM PE = 当前价格 / TTM EPS
  动态PE = 当前价格 / (最新季度EPS × 4)
  复合PEG = TTM PE / 4季度几何平均增速
  FCF Yield = 自由现金流 / 总市值

FCF计算：
  自由现金流 = 经营活动现金流净额 - 购建固定资产等支出
  从东方财富F10 API获取：
    字段 NETCASH_OPERATE（经营活动现金流净额）
    字段 CONSTRUCT_LONG_ASSET（购建固定资产等支出）

评分：
  10分：复合PEG < 0.8 且 TTM PE < 30 且 FCF Yield > 5%
  7分：复合PEG 0.8~1.0 或 TTM PE 30~50
  5分：复合PEG 1.0~1.5 或 TTM PE 50~80
  3分：复合PEG 1.5~2.0 或 TTM PE > 80
  0分：复合PEG > 2.0 或 无法计算

加分项：
  +2分：FCF Yield > 8%（现金流极强）
  +1分：PB < 1（破净）

特殊处理：
  银行/保险：用PB+ROE替代PE+PEG
  周期股：用PB+毛利率趋势替代PE
  亏损股：用PS（市销率）替代PE，PS>20为高估
```

### 3.6 预期差（11%）— 财报vs预期

```
评估内容：
  □ 最近一次财报是否超/不及一致预期
  □ 超预期幅度（>15%为大幅，5~15%为小幅）
  □ 公司是否有最新指引（上调/下调/维持）

评分：
  10分：大幅超预期（>15%）+ 上调指引
  7分：小幅超预期（5~15%）
  5分：符合预期或无数据
  3分：小幅不及预期（-5~15%）
  0分：大幅不及预期（<-15%）+ 下调指引
```

### 3.7 分析师动向（8%）— 预测趋势

```
评估内容：
  □ 近30天分析师上调/下调EPS预测的数量
  □ 一致预期EPS的变化方向
  □ 目标价中位数的变化

评分：
  10分：3家以上券商同时上调EPS>10%
  7分：1~2家券商上调EPS
  5分：无变化或无数据
  3分：1~2家券商下调EPS
  0分：3家以上券商同时下调EPS>15%
```

### 3.8 资金流向（7%）— 实时数据

```
数据源：
  北向资金：沪深港通每日净买入（WebSearch获取）
  融资融券：融资余额变化（WebSearch获取）
  板块资金：板块主力资金净流入（东方财富板块API）

评分：
  10分：北向连续5日净买入 + 融资余额增加 + 板块资金流入
  7分：北向连续3日净买入 或 融资余额增加
  5分：资金流向中性
  3分：北向连续3日净卖出 或 融资余额减少
  0分：北向连续5日净卖出 + 融资余额大幅减少
```

### 3.9 事件驱动（5%）— 基本面事件监控

```
关注事件类型：
  □ 重大合同/订单（营收影响>10%）
  □ 并购重组（可能改变业务结构）
  □ 股东增减持（大股东/管理层）
  □ 股权激励/回购（管理层信心）
  □ 政策变化（行业监管/补贴）
  □ 产品/技术突破（新药获批、技术突破）
  □ 诉讼/合规风险（可能影响基本面）

评分：
  10分：重大正面事件（如大额订单、业绩大幅超预期）
  7分：正面事件（如增持、回购、政策利好）
  5分：无重大事件
  3分：负面事件（如减持、诉讼）
  0分：重大负面事件（如财务造假、核心客户流失）

数据获取：
  东方财富F10 API：ShareholderResearch（股东变动）
  WebSearch："{股票名称} 最新公告 重大事项"
```

### 3.10 风险因子（15%）— 综合风险评估

```
评估维度：
  A. 波动率（5%）
     ATR(20) / 当前价格
     < 2% → 低波动（8分）
     2~4% → 中等波动（5分）
     4~6% → 高波动（3分）
     > 6% → 极高波动（0分）

  B. 流动性（5%）
     日均成交额 > 5亿 → 高流动性（8分）
     日均成交额 1~5亿 → 中等（5分）
     日均成交额 < 1亿 → 低流动性（0分）
     市值 < 50亿 → 小盘股风险（-2分）

  C. 杠杆风险（5%）
     资产负债率 < 30% → 低杠杆（8分）
     资产负债率 30~50% → 中等（5分）
     资产负债率 50~70% → 高杠杆（3分）
     资产负债率 > 70% → 极高杠杆（0分）

  D. 套牢盘压力（从原框架迁移，权重已含在上述维度中）
     距52周高点 < 10% → 套牢盘轻
     距52周高点 10~25% → 有一定套牢盘
     距52周高点 25~50% → 套牢盘密集
     距52周高点 > 50% → 全线套牢
```

## 四、数据源扩展

### 4.1 新增数据源

| 数据类型 | API | 说明 |
|---------|-----|------|
| FCF | 东方财富F10现金流表 | 经营现金流-资本开支 |
| 北向资金 | WebSearch | 沪深港通每日净买入 |
| 融资融券 | WebSearch | 融资余额变化 |
| 股东变动 | 东方财富F10股东研究 | 大股东增减持 |
| 重大事件 | WebSearch + 东方财富公告 | 并购/合同/政策 |

### 4.2 东方财富F10现金流API

```
URL: https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/xjllbAjaxNew?type=0&code={市场代码}{股票代码}

关键字段：
  NETCASH_OPERATE：经营活动产生的现金流量净额
  CONSTRUCT_LONG_ASSET：购建固定资产、无形资产和其他长期资产支付的现金
  FREE_CASHFLOW：自由现金流（如有直接提供）
```

### 4.3 东方财富F10股东研究API

```
URL: https://emweb.securities.eastmoney.com/PC_HSF10/ShareholderResearch/PageAjax?code={市场代码}{股票代码}

关键字段：
  gdrs：股东人数变化
  sdltgd：十大流通股东（含持股变动）
  jgcc：机构持仓
```

```
  收盘价：{价格}  涨跌幅：{涨跌%}

【估值分析】
  TTM PE / 动态PE / 复合PEG / FCF Yield

【四维度评分】
  一、价格分析（30%）
    ① 趋势结构    {分}/16  ×10% = {加权}  ← 可超10分（含周线MACD金叉加分）
    ② 量价关系    {分}/10  ×10% = {加权}
    ③ 价格形态    {分}/10  ×10% = {加权}

  二、基本面分析（35%）
    ④ 增长质量    {分}/12  ×12% = {加权}  ← 可超10分
    ⑤ 估值合理性  {分}/10  ×12% = {加权}
    ⑥ 预期差      {分}/10  ×11% = {加权}

  三、市场情绪（20%）
    ⑦ 分析师动向  {分}/10  ×8%  = {加权}
    ⑧ 资金流向    {分}/10  ×7%  = {加权}
    ⑨ 事件驱动    {分}/10  ×5%  = {加权}

  四、风险评估（15%）
    ⑩ 风险因子    {分}/10  ×15% = {加权}

  ─────────────────────────────────
  综合评分：{总分}/115（理论最高）

【操作结论】
  判断 / 仓位建议 / 买入区间 / 止损 / 目标 / 盈亏比

【关键风险提示】

═══════════════════════════════════════════
```

## 七、与V1框架的对比
