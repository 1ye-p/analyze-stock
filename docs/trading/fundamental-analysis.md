# 基本面 + 估值方法论

> 适用范围：A股/H股个股基本面分析与估值计算
> 最后更新：2026-06-01

---

## 一、财报三问框架

看财报不是看"赚了多少钱"，而是回答三个核心问题：

> **① 钱从哪来的？（收入结构）**
> **② 能持续吗？（增长质量）**
> **③ 超预期了吗？（预期差）**

---

## 二、收入结构拆解

### 2.1 原则：不是所有收入都值同样的估值

| 收入类型 | 估值倍数 | 举例 |
|----------|---------|------|
| 核心业务收入（高增长） | 高PE（50~100+） | 中际旭创的800G光模块收入 |
| 传统业务收入（稳增长） | 低PE（15~30） | 工业富联的传统服务器代工 |
| 投资收益/一次性收入 | 不给估值 | 出售子公司、政府补贴 |

### 2.2 拆解方法

在财报中找到**分产品/分业务收入明细**，单独计算核心业务的：
- 收入占比（是否为主要收入来源）
- 收入增速（同比、环比）
- 毛利率（是否高于其他业务）

```
示例：中际旭创
  800G光模块收入：XX亿（占比60%，同比+120%，毛利率35%）← 核心
  400G光模块收入：XX亿（占比30%，同比-10%，毛利率25%）← 旧产品
  其他光器件收入：XX亿（占比10%，同比+20%，毛利率20%）← 补充
```

**只有拆开看，才知道增长是"真增长"还是"旧业务撑场面"。**

## 三、增长质量四指标

### 3.1 营收增速 vs 净利润增速

| 情况 | 含义 | 判断 |
|------|------|------|
| 营收+30%，净利润+50% | 利润增速>收入增速，**规模效应释放** | 最优 |
| 营收+30%，净利润+30% | 同步增长，正常 | 中性 |
| 营收+30%，净利润+10% | 收入增但利润不增，**增收不增利** | 警惕 |
| 营收+5%，净利润+100% | 利润暴增但收入不增 | 需查是否一次性因素 |

### 3.2 毛利率趋势

| 趋势 | 含义 | 判断 |
|------|------|------|
| 上升 | 产品涨价或产品结构升级 | 强势 |
| 持平 | 竞争格局稳定 | 中性 |
| 下降 | 竞争加剧/价格战 | **行业见顶早期信号** |

**关键洞察**：毛利率连续2个季度下降，是行业周期见顶的最早信号，比收入增速下降更早出现。

### 3.3 经营性现金流 vs 净利润

| 情况 | 含义 |
|------|------|
| 经营现金流 > 净利润 | 利润质量高，钱是真赚到的 |
| 经营现金流 < 净利润 | 利润可能有水分（应收账款堆积） |
| 经营现金流为负 | 危险信号，公司在"烧钱" |

### 3.4 ROE（净资产收益率）

| ROE水平 | 含义 |
|---------|------|
| >20% | 优秀，资本回报率高 |
| 10~20% | 良好 |
| <10% | 一般，需结合行业特性判断 |

**杜邦分解**：ROE = 净利率 × 资产周转率 × 权益乘数

- 高净利率驱动的ROE → 品牌/技术壁垒（最优）
- 高周转率驱动的ROE → 效率驱动（中性）
- 高杠杆驱动的ROE → 风险较高（警惕）

## 四、一致预期体系

### 4.1 谁来定：卖方分析师

券商研究所的行业分析师，通过研读财报、调研公司、与管理层沟通后，给出盈利预测（EPS预测）。

多家券商的预测汇总 → 形成**一致预期（Consensus）** = 所有覆盖分析师预测的中位数。

### 4.2 在哪里查

| 渠道 | 操作方式 | 精确度 |
|------|---------|--------|
| Wind（万得） | 专业终端，机构标配 | 最高 |
| Choice（东方财富） | 免费/低价替代 | 较高 |
| 雪球 | 个股页面→"盈利预测"tab | 够用 |
| 东方财富 | 个股页面→"研报"→汇总 | 够用 |
| 券商研报 | 直接阅读最新研报 | 最原始 |

### 4.3 怎么跟踪预期变化

**预期不是固定的，每天都在变。**

```
预期上调趋势 → 股价大概率上涨 → 持有/加仓
预期下调趋势 → 股价大概率下跌 → 减仓/观望
预期稳定      → 股价震荡       → 等待催化剂
```

**驱动预期变化的因素**：

| 因素 | 预期变化 | 信号来源 |
|------|---------|---------|
| 公司上调全年指引 | 预期上调 | 公司公告/财报电话会 |
| 分析师集体上调EPS | 预期上调 | 券商研报 |
| 行业需求超预期 | 预期上调 | 行业数据/上游订单 |
| 公司下调指引 | 预期下调 | 公司公告 |
| 竞争对手进入/价格战 | 预期下调 | 行业新闻/毛利率变化 |

### 4.4 超预期的量化标准

| 超预期幅度 | 市场反应 | 操作 |
|------------|---------|------|
| > +15% | 强烈正面（跳空涨停） | 坚定持有，回调加仓 |
| +5~15% | 温和正面 | 持有 |
| ±5% | 中性 | 观望 |
| -5~15% | 温和负面 | 关注原因，可能减仓 |
| < -15% | 强烈负面 | 止损 |

### 4.5 关键原则

> **收入超预期 > 利润超预期**

利润可以通过削减成本"做"出来，收入才是真实的市场需求。

> **指引比财报更重要**

财报告诉你"过去怎么样"，指引告诉你"未来怎么样"。

> **超预期但下调指引 = 利好出尽**

这是最危险的组合，很多散户只看财报数字忽略指引，在当天追高被套。

## 五、估值四法

### 5.1 PE估值法（最常用）

```
合理股价 = 预期EPS × 合理PE倍数
```

**PE倍数参考标准**：

| 业务阶段 | 合理PE | 适用标的 |
|----------|--------|---------|
| 高速增长期（收入+50%以上） | 50~80 | 高成长科技股 |
| 稳定增长期（收入+20~50%） | 30~50 | 成熟成长股 |
| 低速增长期（收入+20%以下） | 15~30 | 价值股 |
| 亏损/微利期 | 不适用PE | 用PS代替 |

**止盈设定**：当实际PE接近乐观情景PE时，分批止盈。

### 5.2 PEG估值法（复合PEG体系）

**问题：单季度PEG的低基数陷阱**

用单季度同比增速计算PEG会严重失真：
- 兆易创新：Q1净利+522.8%（去年Q1亏损）→ PEG 0.23（假低估），年度PEG 2.40（真高估）
- 金山办公：Q1净利+445.0%（去年Q1低基数）→ PEG 0.07（假低估），年度PEG 2.58（真高估）

**复合PEG计算方法**：

```
Step 1: 提取最近4个季度单季净利
  Q1单季 = Q1累计值
  Q2单季 = 中报累计 - Q1累计
  Q3单季 = 三季报累计 - 中报累计
  Q4单季 = 年报累计 - 三季报累计

Step 2: 计算各季度YoY增速
  g_n = (本期Qn净利 - 上年Qn净利) / |上年Qn净利|

Step 3: 计算复合增速（几何平均，消除低基数效应）
  G = [(1+g1) × (1+g2) × (1+g3) × (1+g4)]^(1/4) - 1

Step 4: 计算复合PEG
  PEG_composite = TTM PE / (G × 100)
  TTM PE = 当前价格 / TTM EPS
  TTM EPS = 最近4个季度EPS之和
```

**异常处理**：
- 某季度净利为负 → 跳过，用剩余正盈利季度计算，标注"数据不完整({原因})"
- 连续2+季度为负 → 标注"无法计算复合PEG"
- 上年同期为负 → 该季度增速取绝对值，标注"低基数"

**判断标准**：

```
  复合PEG < 0.8 且 TTM PE < 30 → 低估
  复合PEG 0.8~1.0 或 TTM PE 30~50 → 合理偏低
  复合PEG 1.0~1.5 或 TTM PE 50~80 → 合理
  复合PEG 1.5~2.0 或 TTM PE > 80 → 高估
  复合PEG > 2.0 或 无法计算 → 严重高估
```

**双PE输出**：
- TTM PE：基于最近4个季度实际EPS，最可靠
- 动态PE：基于最新季度年化，反映最新趋势
- 两者差异>30%时标注警告

### 5.2.1 实操对比示例

| 标的 | TTM PE | 动态PE | 复合增速 | 复合PEG | 判断 |
|------|--------|--------|---------|---------|------|
| 中际旭创 | 56 | 62 | +80% | 0.70 | 偏低估 |
| 工业富联 | 34 | 38 | +67% | 0.51 | 低估 |
| 生益科技 | 74 | 85 | +92% | 0.80 | 合理偏低 |
| 海光信息 | 251 | 280 | +50% | 5.02 | 严重高估 |

### 5.3 FCF估值法（现金流视角）

```
FCF = 经营活动现金流净额 - 购建固定资产等支出
FCF Yield = FCF / 总市值

判断：
  FCF Yield > 8% → 极强现金流，严重低估
  FCF Yield 5~8% → 强现金流，低估
  FCF Yield 2~5% → 正常
  FCF Yield 0~2% → 偏弱
  FCF Yield < 0 → 现金流为负，需警惕
```

**FCF vs 净利润对比**：
| 情况 | 含义 |
|------|------|
| FCF > 净利润 | 利润质量高，钱是真赚到的 |
| FCF < 净利润 | 利润可能有水分（应收账款堆积） |
| FCF为负 | 危险信号，公司在"烧钱" |

**数据来源**：
```
东方财富F10现金流表 API：
  NETCASH_OPERATE：经营活动现金流净额
  CONSTRUCT_LONG_ASSET：购建固定资产等支出
```

### 5.4 PS估值法（亏损/微利公司适用）

```
PS = 总市值 / 年营业收入

参考：全球最优秀半导体公司PS约30~40
PS > 100 → 泡沫级别
PS 50~100 → 高估
PS 20~50 → 合理
PS < 20 → 低估
```

### 5.4 DCF简化版（现金流折现）

对个人投资者，使用简化DCF：

```
内在价值 = 未来3年自由现金流现值 + 终值现值

简化公式：
  第1~3年现金流 = 当前自由现金流 × (1+增速)^n
  终值 = 第3年现金流 × 合理PE
  折现率 = 10%（A股风险溢价较高）
```

**适用场景**：现金流稳定、可预测性高的公司（如消费、公用事业）。

## 六、止盈目标的系统化设定

| 方法 | 计算方式 | 触发条件 |
|------|---------|---------|
| PE目标法 | 股价达到乐观PE对应价位 | 分批止盈（50%/30%/20%） |
| PEG法 | PEG超过1.5~2.0 | 减仓信号 |
| Fib目标法 | 股价达到前高或Fib扩展位 | 技术止盈 |
| 毛利率拐点法 | 毛利率连续2季下降 | 基本面止盈 |
| 量价背离法 | 股价创新高但成交量萎缩 | 威科夫派发信号 |
| 指引下调法 | 公司下调全年指引 | 立即减仓 |

## 七、EPS预期变动操作矩阵

### 7.1 信号分级

| 级别 | 定义 | 触发条件 | 响应速度 |
|------|------|---------|---------|
| S级（强烈） | 多重信号共振 | 2个以上信号同时 | 立即行动 |
| A级（明确） | 单一强信号 | 1个强信号 | 1~3日内 |
| B级（温和） | 辅助信号 | 弱信号或孤立 | 观察为主 |

### 7.2 EPS上调操作

| 信号 | 级别 | 仓位操作 | 止损调整 | 执行时间 |
|------|------|---------|---------|---------|
| 公司上调指引>20% | S+ | 加至30%上限 | 上移至成本价 | 当日 |
| 公司上调指引10~20% | A+ | 加仓5% | 维持 | 1~3日 |
| 3家+券商上调EPS>10% | A | 加仓3~5% | 上移至近期低点 | 1~3日 |
| 行业需求超预期 | A | 加仓3~5% | 维持 | 等传导确认 |

### 7.3 EPS下调操作

| 信号 | 级别 | 仓位操作 | 止损调整 | 执行时间 |
|------|------|---------|---------|---------|
| 公司下调指引>15% | S- | 减至<15% | 下移至前低 | 当日 |
| 公司下调指引5~15% | A- | 减仓1/3 | 下移至前低 | 1~2日 |
| 3家+券商下调EPS>15% | A- | 减仓1/3~1/2 | 下移至前低 | 1~3日 |
| 竞争对手进入 | A- | 减至半仓 | 下移至前低 | 1~2周 |
| 价格战开始 | S- | 减至<25% | 严格执行 | 立即 |
| 毛利率连续2季下降 | S- | 清仓 | — | 财报后 |

### 7.4 复合信号处理

| 场景 | 基本面 | 技术面 | 操作 |
|------|--------|--------|------|
| A | EPS上调 | 突破新高 | 加仓至上限 |
| B | EPS上调 | 高位滞涨 | 维持，不加仓 |
| C | EPS下调 | 支撑位企稳 | 维持，设止损 |
| D | EPS下调 | 跌破支撑 | **立即减仓或清仓** |

## 八、隐含增长率反推法

从当前PE倒推市场隐含的增长率，判断"市场在赌什么"：

```
隐含增长率 ≈ PE / 合理PEG（取1.0）

示例：
  海光信息 PE=251 → 隐含增长率 ≈ 251%
  实际增速约50% → 差距极大 → 严重高估
```

| 隐含增速 vs 实际增速 | 判断 |
|---------------------|------|
| 隐含增速 < 实际增速 | 可能低估 |
| 隐含增速 ≈ 实际增速 | 合理定价 |
| 隐含增速 > 实际增速 | 高估 |
| 隐含增速 >> 实际增速 | 泡沫 |

## 九、实时行情数据获取

### 9.1 分层降级策略

数据获取采用分层策略：优先 WebFetch → 失败则 curl API。

| 优先级 | 方式 | 数据源 | 说明 |
|--------|------|--------|------|
| 1 | WebFetch | 雪球 | 最直观，但可能被域名安全策略阻止 |
| 2 | curl | 腾讯财经 API | 稳定可靠，GBK编码 |
| 3 | curl | 东方财富 Push API | 备用，JSON格式 |
| 4 | curl | 新浪财经 API | 最后备用 |

### 9.2 腾讯财经 API（推荐）

```bash
# 沪市：sh600570  深市：sz002456  港股：hk00700
curl -s --max-time 10 "https://qt.gtimg.cn/q={市场代码}{股票代码}"
```

返回数据为 `~` 分隔的字符串（GBK编码），关键字段：

| 位置 | 含义 | 位置 | 含义 |
|------|------|------|------|
| [1] | 名称 | [2] | 代码 |
| [3] | 当前价 | [4] | 昨收 |
| [5] | 开盘 | [6] | 成交量(手) |
| [31] | 涨跌额 | [32] | 涨跌幅% |
| [33] | 最高 | [34] | 最低 |
| [37] | 成交额(万) | [38] | 换手率% |
| [39] | PE | [43] | 振幅% |
| [44] | 流通市值(亿) | [45] | 总市值(亿) |
| [46] | PB | [47] | 52周高 |
| [48] | 52周低 | [49] | 量比 |

### 9.3 K线历史数据

```bash
# 前复权日线，最多120根
curl -s --max-time 10 "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={市场代码}{股票代码},day,{起始日期},{结束日期},120,qfq"
```

返回JSON，`qfqday` 或 `day` 数组：`[日期, 开盘, 最高, 最低, 收盘, 成交量]`

### 9.5 事件驱动监控

关注可能改变基本面的事件：
- 重大合同/订单（营收影响>10%）
- 并购重组（可能改变业务结构）
- 股东增减持（大股东/管理层）
- 股权激励/回购（管理层信心）
