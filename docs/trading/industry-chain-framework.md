# 产业链分析通用框架

> 适用范围：A股任意板块的产业链梳理与投资机会识别
> 最后更新：2026-06-01

---

## 一、通用产业链分层模型

任何产业都可以拆解为四层结构：

```
┌─────────────────────────────────────────┐
│           上游：核心零部件/原材料          │
│    技术壁垒最高，利润最早兑现              │
├─────────────────────────────────────────┤
│           中游：集成/制造/加工             │
│    规模效应驱动，利润跟随放量              │
├─────────────────────────────────────────┤
│           下游：终端应用/消费              │
│    需求传导终点，利润最后兑现              │
├─────────────────────────────────────────┤
│           配套：基础设施/服务              │
│    支撑性环节，需求确定但弹性较小          │
└─────────────────────────────────────────┘
```

---

## 二、每层的分析维度

### 2.1 上游分析要点

| 维度 | 关注点 | 信号 |
|------|--------|------|
| 技术壁垒 | 核心技术是否被少数企业垄断 | 国产替代空间大=高弹性 |
| 供需格局 | 产能是否紧缺 | 产能利用率>90%=涨价信号 |
| 客户集中度 | 是否依赖少数大客户 | 集中度高=业绩波动大 |
| 价格传导 | 原材料涨价能否向下游传导 | 能传导=毛利率稳定 |

**上游投资节奏**：在行业景气上行初期最先受益，但价格弹性也最先见顶。

### 2.2 中游分析要点

| 维度 | 关注点 | 信号 |
|------|--------|------|
| 规模效应 | 产能扩张后成本能否下降 | 毛利率随产能利用率上升=规模效应释放 |
| 竞争格局 | 是否进入价格战 | 毛利率下降+新进入者增加=红海化 |
| 订单能见度 | 在手订单覆盖未来几个季度 | 能见度>2季度=业绩确定性高 |
| 技术代际 | 产品是否处于代际升级窗口 | 新一代产品放量=量价齐升 |

**中游投资节奏**：在上游放量后跟进，业绩兑现滞后于上游1~2个季度。

### 2.3 下游分析要点

| 维度 | 关注点 | 信号 |
|------|--------|------|
| 终端需求 | 最终消费者是否买单 | 终端销量数据是最直接的验证 |
| 渗透率 | 产品在终端市场的渗透阶段 | <10%=早期，10~30%=加速，>50%=成熟 |
| 品牌溢价 | 是否有品牌壁垒 | 品牌溢价高=毛利率高且稳定 |
| 政策驱动 | 是否有政策催化 | 政策补贴/标准出台=需求催化 |

**下游投资节奏**：业绩兑现最晚，但一旦放量弹性也最大（渗透率从10%→50%的阶段）。

### 2.4 配套分析要点

| 维度 | 关注点 | 信号 |
|------|--------|------|
| 需求确定性 | 是否为刚需配套 | 产业扩张=配套需求确定性增长 |
| 资本开支 | 是否需要大量前置投入 | 重资产=业绩弹性小但确定性强 |
| 竞争壁垒 | 技术/资质壁垒 | 壁垒高=毛利率稳定 |

## 三、产业链利润迁移规律

**核心规律**：利润在产业链中的分配不是静态的，而是随行业周期迁移。

```
行业周期上行期：
  上游（供不应求，涨价）→ 中游（放量，规模效应）→ 下游（渗透率提升）

行业周期下行期：
  下游（需求萎缩）→ 中游（产能过剩）→ 上游（价格下跌）
```

**投资含义**：

| 阶段 | 利润集中环节 | 投资策略 |
|------|------------|---------|
| 景气上行初期 | 上游（量价齐升） | 重仓上游龙头 |
| 景气上行中期 | 中游（规模效应） | 切换至中游 |
| 景气上行末期 | 下游（渗透率提升） | 布局下游 |
| 景气下行期 | 防御性环节（配套） | 降低仓位，配置防御 |

## 四、行业生命周期定位

```
导入期 ──→ 成长期 ──→ 成熟期 ──→ 衰退期
(0→1)      (1→10)     (10→100)    (负增长)
```

| 阶段 | 收入增速 | 竞争格局 | 估值特征 | 操作策略 |
|------|---------|---------|---------|---------|
| 导入期 | <20%或亏损 | 格局未定 | PE极高或无PE | 高风险高赔率，小仓试探 |
| 成长期 | 30~100% | 龙头初现 | PE 40~80 | **主升浪，重仓龙头** |
| 成熟期 | 10~30% | 格局稳定 | PE 15~30 | 估值回归，稳健配置 |
| 衰退期 | <10%或负 | 红海竞争 | PE 10~15 | 逐步退出 |

**拐点识别信号**（从成长期→成熟期）：
- 龙头公司毛利率开始下降
- 新进入者大幅增加
- 收入增速从50%+降至30%以下
- 产品价格开始下降

## 五、板块轮动判断方法

### 5.1 板块热度评估矩阵

| 指标 | 数据来源 | 热度过高信号 | 冷门信号 |
|------|---------|------------|---------|
| 板块涨幅 | 行业指数 | 近1月涨幅>30% | 近1月跌幅>10% |
| 基金持仓 | 公募季报 | 超配比例创新高 | 低配或减仓 |
| 研报数量 | 券商报告 | 周研报>20篇 | 周研报<3篇 |
| 散户讨论 | 雪球/东财 | 阅读量暴增 | 讨论冷清 |
| 新基金发行 | 基金公司 | 大量主题基金发行 | 无新基金 |

### 5.2 板块轮动节奏（以科技板块为例）

```
第一阶段：算力芯片（概念先行，估值驱动）
  ↓
第二阶段：光互连/PCB（基础设施配套，业绩兑现第一棒）
  ↓
第三阶段：服务器/液冷（集成商放量，业绩兑现第二棒）
  ↓
第四阶段：应用层（商业化落地，业绩兑现第三棒）
  ↓
第五阶段：终端设备（渗透率提升，业绩兑现最后）
```

**判断当前位置的方法**：
- 观察哪些环节的龙头公司已经创52周新高（已兑现）
- 观察哪些环节的龙头公司还在底部（待兑现）
- 资金从已兑现环节流向待兑现环节=轮动信号

## 六、AI板块实例（模板案例）

### 6.1 AI产业链四层结构

```
【上游：算力基础设施】
  GPU/AI芯片 → 光互连/光模块 → 高速PCB/CCL → 存储(HBM)
  海光/寒武纪   中际旭创/天孚    生益科技/沪电    兆易创新

【中游：算力集成与部署】
  AI服务器 → 液冷散热 → 电源管理 → IDC/算力租赁
  工业富联     英维克/高澜   科华数据     万国数据

【下游：AI应用与终端】
  大模型/Agent → AI办公/营销 → AI+制造 → 自动驾驶/机器人
  科大讯飞       金山办公       中控技术     小米/拓普集团

【配套：能源与基础设施】
  电力设备 → 储能 → UPS → 柴发机组
  特变电工   宁德时代  科华数据  潍柴动力
```

### 6.2 AI产业链利润迁移实证

| 时间 | 主线环节 | 代表标的 | 业绩驱动 |
|------|---------|---------|---------|
| 2023~24 | 算力芯片 | 寒武纪、海光 | 概念先行，估值驱动 |
| 2024~25 | 光模块 | 中际旭创、天孚 | 800G放量，业绩第一棒 |
| 2025~26 | PCB/服务器 | 生益科技、工业富联 | AI服务器放量，业绩第二棒 |
| 2026~27 | 液冷散热 | 英维克、曙光数创 | 渗透率提升，业绩第三棒 |
| 2026~27 | AI应用层 | 金山办公、科大讯飞 | 商业化落地，业绩第四棒 |

## 七、拓展模板：如何套用到其他板块

### 7.1 新能源车产业链

```
【上游】锂矿/碳酸锂 → 正极/负极/电解液/隔膜 → 设备
  天齐锂业         宁德时代/恩捷股份              先导智能

【中游】电池Pack → 电驱系统 → 热管理
  宁德时代         汇川技术      三花智控

【下游】整车 → 充电桩 → 运营
  比亚迪/小米      特锐德         曹操出行

【配套】锂电回收 → 储能
  格林美           宁德时代
```

### 7.2 创新药产业链

```
【上游】CRO/CDMO → 原料药 → 设备/耗材
  药明康德          普洛药业      迈瑞医疗

【中游】创新药企（管线价值）
  恒瑞医药/百济神州

【下游】医药流通 → 医院/药店 → 医保支付
  国药控股            爱尔眼科      医保局

  华大基因            卫宁健康
```

### 7.3 使用模板的方法

对任意新板块，按以下步骤操作：

```
Step 1: 识别上中下游四层，列出各层代表公司
Step 2: 分析各层的技术壁垒和竞争格局
Step 3: 判断当前行业处于生命周期哪个阶段
Step 4: 识别利润正在向哪个环节迁移
Step 5: 结合估值和业绩阶段，选择投资标的
Step 6: 参照板块轮动节奏，判断当前主线和未来主线
```
