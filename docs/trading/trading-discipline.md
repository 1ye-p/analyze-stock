# 风控 + 仓位 + 操作纪律

> 适用范围：A股/H股个股交易的风控与仓位管理
> 最后更新：2026-06-01

---

## 一、仓位管理数学纪律

### 1.1 单只标的仓位规则

| 信号级别 | 仓位上限 | 说明 |
|----------|---------|------|
| S级正面（指引上调） | 30%（满仓上限） | 最强信号，敢重仓 |
| A级正面（分析师上调） | 20% | 明确信号，正常仓位 |
| 中性（无明确信号） | 15% | 维持仓位 |
| A级负面（分析师下调） | 10% | 减仓至轻仓 |
| S级负面（指引下调） | 5%或清仓 | 最危险，果断处理 |

### 1.2 行业集中度规则

| 情况 | 同行业最大仓位 |
|------|-------------|
| 行业景气上行，EPS上调趋势 | 50%（上限） |
| 行业景气平稳 | 30% |
| 行业景气下行，EPS下调趋势 | 15% |

### 1.3 亏损与回本的数学关系

| 亏损幅度 | 回本所需涨幅 |
|----------|------------|
| -10% | +11% |
| -20% | +25% |
| -30% | +43% |
| -50% | +100% |

**铁律**：止损必须设在-10%到-20%。亏损超过30%，回本难度呈指数级上升。

## 二、止损设置逻辑

### 2.1 技术止损

```
技术止损位 = 近期关键支撑位下方 3~5%
```

支撑位来源：
- 斐波那契回撤位（23.6%/38.2%/50%/61.8%）
- 近期低点（52周低点、近期波段低点）
- 均线支撑位（30日/60日/120日均线）

### 2.2 基本面止损

```
基本面止损 = 当EPS一致预期下调至买入时预期的80%以下
```

示例：
```
买入时预期2026 EPS = 25元
当前一致预期下调至20元（下调20%）
→ 20/25 = 80%，触发基本面止损
```

### 2.3 联合止损

```
实际止损位 = max（技术止损位，基本面止损位）
```

取两者中更严格的那个执行。

### 2.4 止损执行纪律

- 止损触发后，**至少观望2周**，不要急于买回
- 止损是保护本金的最后防线，**触发就执行，不讨价还价**
- 如果止损后股价反弹，不要后悔——纪律比单次对错更重要

## 三、止盈分批执行规则

### 3.1 分批止盈框架

```
第一批止盈（+30%）：卖出 50% 仓位
  → 锁定大部分利润，降低持仓成本

第二批止盈（+50%）：再卖出 30% 仓位
  → 进一步锁定利润，剩余仓位成本极低

剩余 20%：持有至趋势反转信号出现
  → 让利润奔跑
```

### 3.2 止盈触发条件（基本面角度）

| 条件 | 操作 |
|------|------|
| 连续2个季度业绩不及一致预期 | 全部止盈 |
| 毛利率连续2个季度下降 | 全部止盈 |
| 公司下调全年指引 | 减仓50%+ |
| PEG超过2.0 | 开始分批止盈 |
| 达到PE目标价 | 分批止盈 |

### 3.3 止盈触发条件（技术面角度）

| 条件 | 操作 |
|------|------|
| 股价创新高但成交量萎缩（量价背离） | 减仓信号 |
| 出现射击之星/黄昏之星等见顶形态 | 减仓信号 |
| 跌破20日均线且3日内未收复 | 减仓50% |
| 跌破60日均线 | 全部止盈 |

## 四、信号分级体系

### 4.1 信号级别定义

| 级别 | 定义 | 触发条件 | 响应速度 |
|------|------|---------|---------|
| S级（强烈） | 多重信号共振，方向明确 | 2个以上信号同时出现 | 立即行动 |
| A级（明确） | 单一强信号，方向清晰 | 1个强信号出现 | 1~3日内行动 |
| B级（温和） | 辅助信号，方向待确认 | 弱信号或孤立信号 | 观察为主 |

### 4.2 正面信号分级

| 信号 | 级别 |
|------|------|
| 公司上调全年指引>20% | S+ |
| 公司上调指引10~20% | A+ |
| 3家以上券商同时上调EPS>10% | A |
| 行业需求数据超预期 | A |
| 1~2家券商上调EPS | B |

### 4.3 负面信号分级

| 信号 | 级别 |
|------|------|
| 公司下调全年指引>15% | S- |
| 价格战开始（产品降价>10%） | S- |
| 毛利率连续2季下降 | S- |
| 公司下调指引5~15% | A- |
| 3家以上券商同时下调EPS>15% | A- |
| 竞争对手进入 | A- |
| 1~2家券商下调EPS | B |

## 五、复合信号场景处理

### 场景A：EPS上调 + 技术面突破

```
基本面：分析师上调EPS
技术面：股价突破前高，放量

操作：双重共振 → 加仓至上限
止损：设在突破位下方3~5%
止盈：Fib扩展位或PE目标价
```

### 场景B：EPS上调 + 技术面走弱

```
基本面：分析师上调EPS
技术面：股价高位放量滞涨/射击之星

操作：信号矛盾 → 维持仓位，不加仓
原因：技术面可能反映"利好出尽"
等待：技术面修复后再考虑加仓
```

### 场景C：EPS下调 + 技术面支撑

```
基本面：个别分析师下调EPS
技术面：股价在关键支撑位企稳

操作：基本面偏空 + 技术面偏多 → 维持仓位
止损：设在支撑位下方
观察：等待更多信号明确
```

### 场景D：EPS下调 + 技术面破位（最危险）

```
基本面：分析师集体下调EPS
技术面：股价跌破关键支撑，放量下跌

操作：双重负面共振 → 立即减仓或清仓
这是最明确的"跑"信号，绝不犹豫
```

## 六、操作执行时间纪律

| 信号类型 | 响应时间 | 原因 |
|----------|---------|------|
| 公司下调指引 | **当日/次日** | 最危险信号，市场会快速反应 |
| 3家以上券商同时下调 | **1~3日** | 信号明确，不宜拖延 |
| 单家券商下调 | **观察1周** | 可能是噪音，等更多确认 |
| 行业价格战信号 | **1~2周内逐步减仓** | 长期影响，不必恐慌但要行动 |
| 公司上调指引 | **当日/次日** | 正面信号，及时加仓 |
| 分析师集体上调 | **1~3日** | 跟随但不追高 |

## 七、心理纪律清单

### 7.1 追涨的数学本质

> 追涨 = 用有限的本金去博取别人已经吃完的利润，承担别人已经规避的风险。

**铁律**：52周新高附近不追涨。哪怕再涨30%也不后悔。

### 7.2 割肉追涨的陷阱

当出现"手里的在跌，外面的在涨"时：

```
最危险的想法：割肉去追外面的
最常见的结果：旧仓割在低点，新仓追在高点，双杀

正确做法：
  1. 评估手里标的的基本面是否恶化
  2. 如果基本面没变，耐心持有
  3. 外面的机会用空余仓位参与，不动旧仓
```

### 7.3 每日纪律

```
□ 每天只看一次盘，避免情绪化操作
□ 不在亏损时加仓（越跌越买的陷阱）
□ 不在盈利时过度自信（放松风控的开始）
□ 计划你的交易，交易你的计划
```

### 7.4 操作纪律总表

```
□ 单只标的最大仓位：总资金的30%（绝对上限）
□ 同行业最大仓位：总资金的50%
□ 止损线：单只标的-10%减半仓，-20%清仓
□ 止盈线：单只标的+30%止盈1/3，+50%再止盈1/3
□ S级信号出现时，绝不犹豫
□ 信号矛盾时，仓位不动
□ 止损触发后，至少观望2周
□ 52周新高附近不追涨
□ EPS下调+技术破位 = 立即跑
```

## 八、技术分析评分体系（10维度）

用于综合评估个股的技术面+基本面状态，每维度0~10分，加权计算总分。

### 8.1 评分维度与权重

| 维度 | 权重 | 类别 | 评分标准 |
|------|------|------|---------|
| 趋势结构（道氏） | 15% | 技术 | 高低点序列完整性、趋势方向 |
| 量价关系（威科夫） | 15% | 技术 | 吸筹/派发信号、供给枯竭/涌现 |
| 均线/KDJ/MACD | 10% | 技术 | 策略核心条件（KDJ<13+MACD>0轴） |
| Price Action形态 | 10% | 技术 | K线形态、口袋支点、射击之星 |
| 斐波那契/枢轴位 | 5% | 技术 | 是否处于关键支撑/阻力位 |
| 套牢盘供给压力 | 10% | 技术 | 上方套牢盘密集程度 |
| EPS增长质量 | 10% | 基本面 | 营收vs利润增速、毛利率趋势 |
| 估值合理性 | 10% | 基本面 | PE/PEG是否合理 |
| 预期差方向 | 10% | 基本面 | 超/不及一致预期 |
| 主线概念强度 | 5% | 板块 | 是否当前市场主线 |

### 8.2 综合评分解读

| 总分 | 判断 | 操作建议 |
|------|------|---------|
| 80~100 | 强烈看多 | 重仓，积极加仓 |
| 65~80 | 看多 | 持有，回调加仓 |
| 50~65 | 中性 | 轻仓观望，等信号 |
| 35~50 | 偏空 | 减仓，设好止损 |
| 0~35 | 看空 | 清仓或回避 |

### 8.3 各维度评分参考标准

**趋势结构（道氏理论）**：
- 10分：高点升、低点升的完美上升趋势
- 7分：上升趋势，但近期有回调
- 5分：横盘震荡，方向不明
- 3分：下降趋势，但接近支撑
- 0分：下降趋势，持续创新低

**量价关系（威科夫）**：
- 10分：缩量企稳+需求回归（底部吸筹完成）
- 7分：缩量下跌（供给枯竭，底部信号）
- 5分：量价正常，无明显信号
- 3分：放量下跌（供给涌现，危险）
- 0分：放量暴跌（恐慌性抛售）

**均线/KDJ/MACD**：
- 10分：KDJ<13 + MACD在0轴上方 + 均线支撑
- 7分：KDJ超卖 + MACD接近0轴
- 5分：指标中性
- 3分：KDJ高位 + MACD死叉
- 0分：KDJ超买 + MACD深度负值

**Price Action形态**：
- 10分：口袋支点 + 缩量小阴小阳整理
- 7分：底部形态（双底/头肩底）
- 5分：无明显形态
- 3分：高位滞涨/射击之星
- 0分：放量大阴线/破位

**斐波那契/枢轴位**：
- 10分：处于多个Fib支撑共振位
- 7分：处于单一Fib支撑位
- 5分：处于中间区域
- 3分：处于Fib阻力位
- 0分：突破所有支撑，下方无参考

**套牢盘供给压力**：
- 10分：52周新高，几乎无套牢盘
- 7分：上方套牢盘较轻
- 5分：上方有一定套牢盘
- 3分：上方套牢盘密集
- 0分：全线套牢，阻力极重

**EPS增长质量**：
- 10分：营收+50%以上，利润增速>营收增速，毛利率上升
- 7分：营收+20~50%，利润同步增长
- 5分：营收+10~20%，增长平稳
- 3分：营收增速<10%或增收不增利
- 0分：营收负增长或亏损扩大

**估值合理性（PEG）**：
- 10分：PEG < 0.8
- 7分：PEG 0.8~1.0
- 5分：PEG 1.0~1.5
- 3分：PEG 1.5~2.0
- 0分：PEG > 2.0

**预期差方向**：
- 10分：大幅超预期（>15%）+ 上调指引
- 7分：小幅超预期（5~15%）
- 5分：符合预期
- 3分：小幅不及预期（-5~15%）
- 0分：大幅不及预期（<-15%）+ 下调指引

**主线概念强度**：
- 10分：当前市场最强主线，资金持续流入
- 7分：活跃板块，有持续催化
- 5分：普通板块，关注度一般
- 3分：冷门板块，资金流出
- 0分：过气板块，无人关注

## 九、数据获取方式

评分体系依赖实时行情和历史K线数据。详细获取方式参见 `fundamental-analysis.md` 第九章。

**快速参考**：

```bash
# 腾讯财经 API（行情，GBK编码，市场代码：sh/sz/hk）
curl -s --max-time 10 "https://qt.gtimg.cn/q={市场代码}{股票代码}"

# K线历史数据（前复权日线）
curl -s --max-time 10 "https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param={市场代码}{股票代码},day,{起始日期},{结束日期},120,qfq"

# 基本面数据（财报指标，市场代码大写：SH/SZ）
curl -s --max-time 10 "https://emweb.securities.eastmoney.com/PC_HSF10/NewFinanceAnalysis/ZYZBAjaxNew?type=0&code={市场代码}{股票代码}" -H "Referer: https://emweb.securities.eastmoney.com" -H "User-Agent: Mozilla/5.0"

# 股东数据（股东人数/十大股东/机构持仓）
curl -s --max-time 10 "https://emweb.securities.eastmoney.com/PC_HSF10/ShareholderResearch/PageAjax?code={市场代码}{股票代码}" -H "Referer: https://emweb.securities.eastmoney.com" -H "User-Agent: Mozilla/5.0"
```

> 行情API市场代码小写（sh/sz），基本面API市场代码大写（SH/SZ）
