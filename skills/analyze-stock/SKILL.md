#### 1.5 TTM PE + 复合PEG计算（必须执行）

从东方财富F10 API提取8期数据，计算单季净利和复合增速：

```
单季净利提取：
  Q1单季 = Q1累计值
  Q2单季 = 中报累计 - Q1累计
  Q3单季 = 三季报累计 - 中报累计
  Q4单季 = 年报累计 - 三季报累计

YoY增速：
  g_n = (本期Qn净利 - 上年Qn净利) / |上年Qn净利|

复合增速（几何平均，消除低基数效应）：
  G = [(1+g1) × (1+g2) × (1+g3) × (1+g4)]^(1/4) - 1

TTM PE = 当前价格 / TTM EPS
  TTM EPS = 最近4个季度EPS之和
动态PE = 当前价格 / (最新季度EPS × 4)

复合PEG = TTM PE / (G × 100)
```

异常处理：
- 某季度净利为负 → 跳过，用剩余正盈利季度计算，标注"数据不完整({原因})"
- 连续2+季度为负 → 标注"无法计算复合PEG"
- 上年同期为负 → 该季度增速取绝对值，标注"低基数"

#### 1.6 FCF计算（必须执行）

```
FCF = 经营活动现金流净额 - 购建固定资产等支出
FCF Yield = FCF / 总市值

数据来源：东方财富F10现金流表
  NETCASH_OPERATE：经营活动现金流净额
  CONSTRUCT_LONG_ASSET：购建固定资产等支出
```

### Step 2: 价格分析（30%）

#### 2.1 趋势结构（10%）— 量化 + 周线MACD金叉加分

```
基础评分（道氏理论高低点序列）：
  高点升：最近3个波段高点，每个比前一个高>3%
  低点升：最近3个波段低点，每个比前一个高>3%

  10分：高点升+低点升，且距52周高点<10%
  7分：高点升+低点升，但近期有回调（距高点10~25%）
  5分：横盘震荡（高低点变化<3%）
  3分：高点降或低点降（下降趋势）
  0分：持续创新低（高点降+低点降）

周线MACD金叉加分（允许超过10分）：
  +3分：周线MACD金叉（DIF上穿DEA，且在0轴附近或上方）
  +2分：金叉前有4周以上窄幅震荡
         窄幅震荡定义：过去4~8周的周振幅均值/均价 < 8%
  +1分：金叉时成交量放大（周成交量>前4周均值的1.2倍）

  最强信号：横盘突破(10) + 周线MACD金叉(3) + 窄幅震荡(2) + 放量(1) = 16分

周线60MA趋势过滤（必须检查）：
  股价 > 周线60MA → 不减分（长期趋势完好）
  股价 < 周线60MA → -3分（长期趋势破位）

  计算方式：从K线数据按周聚合，计算60周收盘价均值
  评分范围：-3 ~ 16分
```

#### 2.2 量价关系（10%）— 威科夫阶段

```
评分：
  10分：缩量企稳+需求回归（底部吸筹完成，Spring确认）
  7分：缩量下跌（供给枯竭，底部信号）
  5分：量价正常，无明显信号
  3分：放量下跌（供给涌现）
  0分：放量暴跌（恐慌性抛售）
```

输出：量比解读、威科夫阶段判断（吸筹/派发/主升/下跌）

#### 2.3 价格形态（10%）— K线形态

```
评分：
  10分：口袋支点（放量阳线，量超前10日最大阴线量）
  7分：底部形态（双底/头肩底）
  5分：无明显形态
  3分：高位滞涨/射击之星
  0分：放量大阴线/破位
```

### Step 3: 基本面分析（35%）

#### 3.1 增长质量（12%）

```
评估指标：
  □ 营收增速（Q1同比 + 年度同比）
  □ 净利增速（Q1同比 + 年度同比）
  □ 毛利率趋势（季度环比）
  □ 经营现金流 vs 净利润

评分：
  10分：营收+50%以上，利润增速>营收增速，毛利率上升，现金流>净利
  7分：营收+20~50%，利润同步增长，毛利率稳定
  5分：营收+10~20%，增长平稳
  3分：营收增速<10%或增收不增利
  0分：营收负增长或亏损扩大

加分项（允许超过10分）：
  +2分：毛利率连续3个季度上升
  +1分：经营现金流/净利润 > 1.5（利润质量极高）
```

#### 3.2 估值合理性（12%）

```
核心指标：
  TTM PE、动态PE、复合PEG、FCF Yield

评分：
  10分：复合PEG < 0.8 且 TTM PE < 30 且 FCF Yield > 5%
  7分：复合PEG 0.8~1.0 或 TTM PE 30~50
  5分：复合PEG 1.0~1.5 或 TTM PE 50~80
  3分：复合PEG 1.5~2.0 或 TTM PE > 80
  0分：复合PEG > 2.0 或 无法计算

加分项：
  +2分：FCF Yield > 8%（现金流极强）
  +1分：PB < 1（破净）

特殊处理：
  银行/保险：用PB+ROE替代PE+PEG
  周期股：用PB+毛利率趋势替代PE
  亏损股：用PS（市销率）替代PE，PS>20为高估
```

#### 3.3 预期差（11%）

```
评估内容：
  □ 最近一次财报是否超/不及一致预期
  □ 超预期幅度（>15%为大幅，5~15%为小幅）
  □ 公司是否有最新指引（上调/下调/维持）

评分：
  10分：大幅超预期（>15%）+ 上调指引
  7分：小幅超预期（5~15%）
  5分：符合预期或无数据
  3分：小幅不及预期（-5~15%）
  0分：大幅不及预期（<-15%）+ 下调指引
```

### Step 4: 市场情绪（20%）

#### 4.1 分析师动向（8%）

```
评估内容：
  □ 近30天分析师上调/下调EPS预测的数量
  □ 一致预期EPS的变化方向
  □ 目标价中位数的变化

评分：
  10分：3家以上券商同时上调EPS>10%
  7分：1~2家券商上调EPS
  5分：无变化或无数据
  3分：1~2家券商下调EPS
  0分：3家以上券商同时下调EPS>15%
```

#### 4.2 资金流向（7%）

```
数据源：
  北向资金：沪深港通每日净买入（WebSearch获取）
  融资融券：融资余额变化（WebSearch获取）

评分：
  10分：北向连续5日净买入 + 融资余额增加
  7分：北向连续3日净买入 或 融资余额增加
  5分：资金流向中性
  3分：北向连续3日净卖出 或 融资余额减少
  0分：北向连续5日净卖出 + 融资余额大幅减少
```

#### 4.3 事件驱动（5%）

```
关注事件类型：
  □ 重大合同/订单（营收影响>10%）
  □ 并购重组（可能改变业务结构）
  □ 股东增减持（大股东/管理层）
  □ 股权激励/回购（管理层信心）
  □ 政策变化（行业监管/补贴）
  □ 产品/技术突破
  □ 诉讼/合规风险

评分：
  10分：重大正面事件（如大额订单、业绩大幅超预期）
  7分：正面事件（如增持、回购、政策利好）
  5分：无重大事件
  3分：负面事件（如减持、诉讼）
  0分：重大负面事件（如财务造假、核心客户流失）
```

### Step 5: 风险评估（15%）

#### 5.1 风险因子综合评估（15%）

```
A. 波动率（5%）
   ATR(20) / 当前价格
   < 2% → 低波动（8分）
   2~4% → 中等波动（5分）
   4~6% → 高波动（3分）
   > 6% → 极高波动（0分）

B. 流动性（5%）
   日均成交额 > 5亿 → 高流动性（8分）
   日均成交额 1~5亿 → 中等（5分）
   日均成交额 < 1亿 → 低流动性（0分）
   市值 < 50亿 → 小盘股风险（-2分）

C. 杠杆风险（5%）
   资产负债率 < 30% → 低杠杆（8分）
   资产负债率 30~50% → 中等（5分）
   资产负债率 50~70% → 高杠杆（3分）
   资产负债率 > 70% → 极高杠杆（0分）

D. 套牢盘压力（含在上述维度中）
   距52周高点 < 10% → 套牢盘轻
   距52周高点 10~25% → 有一定套牢盘
   距52周高点 25~50% → 套牢盘密集
   距52周高点 > 50% → 全线套牢
```

## 财报日历预警（每次分析时自动检查）

### 数据获取

```
首次分析时通过WebSearch获取财报日期：
  搜索："{股票名称} {代码} 财报发布日期 2026"

缓存到：data/calendar/earnings.json
缓存有效期：7天（超过7天重新获取）
```

### 数据结构

```json
{
  "601138": {
    "name": "工业富联",
    "next_report": "2026-08-28",
    "type": "中报",
    "last_checked": "2026-06-05"
  }
}
```

### 预警级别

```
距财报 > 30天：无提示
距财报 14~30天：⚡ 提示（"财报临近，注意仓位"）
距财报 7~14天：⚠️ 警告（"财报前14天，建议减仓或设好止损"）
距财报 < 7天：🔴 高风险（"财报即将发布，重大不确定性"）
```

### 输出格式

```
【财报日历预警】
  ⚠️ 药明康德：中报预计2026-08-15发布（距今71天）
  ⚡ 工业富联：中报预计2026-08-28发布（距今84天）
  ✅ 恩捷股份：最近财报已发布，无近期风险
```

## 注意事项

1. **严格使用中文**进行所有交流
2. **不预测确切点位**，给出区间范围
3. **强调风险**，每次分析必须包含风险提示

8. **周线MACD金叉**需在K线数据中验证，不可编造
