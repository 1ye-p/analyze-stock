**TTM PE + 复合PEG计算**（必须执行）：

API返回数据按时间倒序排列，需提取**8期**数据计算完整4季度YoY增速：

```
索引  报告期      含义           提取单季值
[0]   2026Q1    Q1累计         直接使用
[1]   2025年报   全年累计       [1]-[2]=2025Q4
[2]   2025三季报  Q1+Q2+Q3      [2]-[3]=2025Q3
[3]   2025中报   Q1+Q2         [3]-[4]=2025Q2
[4]   2025一季报  Q1累计         直接使用（2025Q1）
[5]   2024年报   上年全年       [5]-[6]=2024Q4
[6]   2024三季报  Q1+Q2+Q3      [6]-[7]=2024Q3
[7]   2024中报   Q1+Q2         [7]-[8]=2024Q2
[8]   2024一季报  Q1累计         直接使用（2024Q1）
```

> 如果API只返回6期，则只能计算部分季度的YoY增速，需标注"数据不完整"

计算公式：
```
TTM净利润 = Q1(最新) + Q4 + Q3 + Q2
TTM EPS = TTM净利润 / 总股本（从行情API获取市值/价格反推）
TTM PE = 当前价格 / TTM EPS
动态PE = 当前价格 / (最新季度EPS × 4)

单季增速 g_n = (本期Qn净利 - 上年Qn净利) / |上年Qn净利|
复合增速 G = [(1+g1)×(1+g2)×(1+g3)×(1+g4)]^(1/4) - 1
复合PEG = TTM PE / (G × 100)
```

异常处理：
- 某季度净利为负 → 跳过，用剩余正盈利季度计算，标注"数据不完整({原因})"
- 连续2+季度为负 → 标注"无法计算复合PEG"
- 上年同期为负 → 该季度增速取绝对值，标注"低基数"
- 上年同期为0 → 跳过，标注"上年同期为零"

解析示例（获取6期数据）：
```bash
curl -s --max-time 10 "{URL}" -H "Referer: https://emweb.securities.eastmoney.com" -H "User-Agent: Mozilla/5.0" | python3 -c "
import json,sys
data = json.load(sys.stdin)
items = data.get('data',[])[:6]
for item in items:
    name = item.get('REPORT_DATE_NAME','')
    rev = (item.get('TOTALOPERATEREVE') or 0)/1e8
    rev_yoy = item.get('TOTALOPERATEREVETZ') or 0
    profit = (item.get('PARENTNETPROFIT') or 0)/1e8
    profit_yoy = item.get('PARENTNETPROFITTZ') or 0
    eps = item.get('EPSJB') or 0
    roe = item.get('ROEJQ') or 0
    margin = item.get('XSMLL') or 0
    print(f'{name}: 营收{rev:.1f}亿({rev_yoy:+.1f}%) 净利{profit:.1f}亿({profit_yoy:+.1f}%) EPS={eps:.2f} ROE={roe:.1f}% 毛利率={margin:.1f}%')
"
```

#### 3.3 估值合理性（10%）— 复合PEG体系

**必须同时输出TTM PE和动态PE**：

```
TTM PE = 当前价格 / TTM EPS（基于最近4个季度实际EPS）
动态PE = 当前价格 / (最新季度EPS × 4)
差异 = (动态PE - TTM PE) / TTM PE × 100%
差异 > 30% 时标注警告
```

**复合PEG计算**（消除低基数效应）：

```
Step 1: 从东方财富F10 API提取6期财报数据
Step 2: 反推单季净利
  Q1单季 = Q1累计值
  Q2单季 = 中报累计 - Q1累计
  Q3单季 = 三季报累计 - 中报累计
  Q4单季 = 年报累计 - 三季报累计

Step 3: 计算各季度YoY增速
  g_n = (本期Qn净利 - 上年Qn净利) / |上年Qn净利|

Step 4: 计算复合增速（几何平均）
  G = [(1+g1) × (1+g2) × (1+g3) × (1+g4)]^(1/4) - 1

Step 5: 计算复合PEG
  PEG_composite = TTM PE / (G × 100)
```

**异常处理**：
- 某季度净利为负 → 跳过，用剩余正盈利季度计算，标注"数据不完整({原因})"
- 连续2+季度为负 → 标注"无法计算复合PEG"
- 上年同期为负 → 该季度增速取绝对值，标注"低基数"
- 上年同期为0 → 跳过，标注"上年同期为零"

**判断标准**：
```
  复合PEG < 0.8 且 TTM PE < 30 → 低估
  复合PEG 0.8~1.0 或 TTM PE 30~50 → 合理偏低
  复合PEG 1.0~1.5 或 TTM PE 50~80 → 合理
  复合PEG 1.5~2.0 或 TTM PE > 80 → 高估
  复合PEG > 2.0 或 无法计算 → 严重高估
```

```
评分标准：
  10分：复合PEG < 0.8 且 TTM PE < 30
  7分：复合PEG 0.8~1.0
  5分：复合PEG 1.0~1.5
  3分：复合PEG 1.5~2.0
  0分：复合PEG > 2.0 或 无法计算
```
